# Contributing

Use Python 3.12 and `uv sync --frozen`. Run `uv run ruff check .`,
`uv run ruff format --check .`, `uv run mypy src` and `uv run pytest -q`.
Keep changes focused and add regression tests for altered behavior. Research
changes must identify the hypothesis, source reference, protocol and ablation.
Preserve independent expert parameters, temporal boundaries and candidate evidence.
Never submit data, model weights, credentials or synthetic results labeled as real.
Document measured compute and tuning budgets before making comparative claims.
